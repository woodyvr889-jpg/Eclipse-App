# 🌘 Solar Eclipse Guide UK 2026

A mobile-first offline PWA that helps users safely experience the 2026 solar eclipse.

## Features

- 🌘 Eclipse countdown
- 🧭 Eclipse finder using device sensors
- 📍 Location support
- 🌞 Interactive eclipse animation
- 🛡 Safety guides
- 📺 Live stream links
- 📱 Offline PWA support

## Built With

- HTML
- CSS
- JavaScript
- Progressive Web App technology
